# models/

Locally downloaded weights and exported models. **Model files are not committed** (`*.pt`, `*.onnx`, `*.engine` are ignored).

## Planned contents

| File | How it will be obtained |
|------|-------------------------|
| `yolov8n.pt` | Pretrained Ultralytics weights, downloaded on first use |
| `yolov8n.onnx` | Generated by the planned export step (`scripts/export_onnx.py`, not yet implemented) |

The export procedure, opset, and numerical validation tolerances will be documented here once the export step exists.
